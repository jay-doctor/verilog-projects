# ⚙️ Verilog HDL Projects (EDA Playground)

This repository showcases my Verilog HDL projects designed and simulated on **EDAPlayground**.  
Each module demonstrates digital logic design concepts, memory organization, and finite state machine (FSM) implementation — essential skills for RTL, FPGA, and ASIC design workflows.

---

## 🧩 Project List

| Project | Description | Live Link |
|----------|--------------|-----------|
| **Vending Machine** | Finite State Machine (FSM)-based vending system that dispenses items based on coin input combinations. Demonstrates FSM design and sequential logic. | [View on EDAPlayground](https://www.edaplayground.com/) |
| **Single Port RAM** | Verilog implementation of a single-port RAM with read and write operations using behavioral modeling. | [View on EDAPlayground](https://www.edaplayground.com/) |
| **Dual Port RAM** | Dual-access memory supporting simultaneous read and write operations on different addresses. Demonstrates memory design and synchronization. | [View on EDAPlayground](https://www.edaplayground.com/) |
| **ROM Module** | Read-Only Memory module implemented using case statements, illustrating fixed data storage in hardware. | [View on EDAPlayground](https://www.edaplayground.com/) |
