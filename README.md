# ⚙️ Verilog HDL Projects (EDA Playground)

This repository showcases my Verilog HDL projects designed and simulated on **EDAPlayground**.  
Each module demonstrates digital logic design concepts, memory organization, and finite state machine (FSM) implementation — essential skills for RTL, FPGA, and ASIC design workflows.

---

## 🧩 Project List

| Project | Description | Live Link |
|----------|--------------|-----------|
| **Vending Machine** | Finite State Machine (FSM)-based vending system that dispenses items based on coin input combinations. Demonstrates FSM design and sequential logic. | [View on EDAPlayground](https://www.edaplayground.com/x/BHeE) |
| **Single Port RAM** | Verilog implementation of a single-port RAM with read and write operations using behavioral modeling. | [View on EDAPlayground](https://www.edaplayground.com/x/dG7C) |
| **Dual Port RAM** | Dual-access memory supporting simultaneous read and write operations on different addresses. Demonstrates memory design and synchronization. | [View on EDAPlayground](https://www.edaplayground.com/x/ewWn) |
| **ROM Module** | Read-Only Memory module implemented using case statements, illustrating fixed data storage in hardware. | [View on EDAPlayground](https://www.edaplayground.com/x/Ht9j) |
| **I²C Master-Slave Simulation in Verilog** | This project implements a master-slave I²C communication protocol in Verilog. It consists of three modules: i2c_slave_controller – Core I²C logic handling data transfer, ACK/NACK, and SCL/SDA operations. i2c_controller – Master module wrapping the core logic and interfacing with the testbench. i2c_controller_tb – Testbench generating clocks, resets, stimulus, and verifying correct data transfer. The simulation demonstrates bidirectional data flow, START/STOP conditions, address/data transmission, and ACK/NACK handling on a shared I²C bus. The project is fully modular, easy to reuse, and simulates realistic I²C behavior for embedded system applications. Key Features: I²C master-slave communication protocol. Full testbench for functional verification. Modular design for reuse in larger systems. Simulation of START, STOP, data, and ACK/NACK sequences | [View on EDAPlayground](https://www.edaplayground.com/x/99__) |
